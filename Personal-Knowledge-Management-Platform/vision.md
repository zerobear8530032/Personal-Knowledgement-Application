# Project: Personal Learning System

## Vision

Create an application that helps people capture knowledge,
organize resources, and improve retention using effective
learning techniques.

The goal is not just to store notes, but to help users
remember and apply what they learn.

---

# Problem

People consume a lot of information but struggle to:
- organize knowledge
- find information later
- revise consistently
- retain what they learn

---

# Target Users

- Students
- Developers
- Interview preparation candidates
- Self learners

---

# Product Roadmap

## Phase 1: Knowledge Storage Foundation

Goal:
Create a reliable system to store and manage knowledge.

Features:
- User management
- Authentication
- Notes CRUD
- Basic relationships
- Attachments
- Basic organization


## Phase 2: Knowledge Organization

Goal:
Make information easier to find and manage.

Features:
- Search
- Tags
- Folders
- Nested folders
- Resource management
- Filtering


## Phase 3: Learning System

Goal:
Help users retain knowledge.

Features:
- Study sessions
- Pomodoro
- Revision scheduling
- Spaced repetition
- Flashcards
- Active recall


## Phase 4: Intelligence Layer

Goal:
Use AI to improve learning.

Features:
- Summaries
- Quiz generation
- Flashcard generation
- Related notes
- Learning recommendations
